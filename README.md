# SakuraMedia 女优资料补全

从 JavBus 补全 SakuraMedia 本地女优资料。

## 安装

在 SakuraMedia 的「系统设置 → 插件」上传本插件的 ZIP 并启用。
JavBus 在部分网络环境可能需要通过代理访问；如无法连接，请在部署 SakuraMedia 后端容器时自行配置代理。

## 工作方式

- 默认每天 05:00 运行，使用宿主调度时区；手动运行没有额外参数。
- 扫描未明确标记为男性的演员。可用 `subscribed_only` 只处理已订阅演员。
- 已订阅演员优先；其余按关联的非合集影片数量降序，同数按演员 ID 升序。
- 按本地姓名和别名搜索 JavBus 女优，成功后把 `/star/<id>` 或 `/uncensored/star/<id>` 缓存在插件状态中，后续直接读取演员页。
- 只接受规范化后完全同名的搜索结果；同名条目有多个时逐个打开，取资料最全的那个，身份不一致的条目跳过。
- 补全生日、身高、三围、罩杯和出生地；JavBus 不提供血型，插件不会自动补血型。
- JavBus 演员页使用日文名。只有中文名或旧艺名时可能搜不到，请在本地演员资料里补充日文别名。
- 只写入空值；不会覆盖人工或其他插件持有的字段。性别由宿主影片元数据维护，插件不写性别。
- 资料页已无缺失字段的演员不会重复请求；搜索无结果、身份不一致或页面没有资料等稳定结果会停止重试，姓名或别名变化后自动重新尝试。
- 从 0.1.0 升级时会把旧版本判为无结果、同名多页、身份不一致或无资料而停止的演员重新排入队列，自动重跑一次。
- 请求遵循 `request_interval_seconds`，默认 1 秒一次；遇到人机验证会中止本轮。

## 配置（可选）

在插件管理页通过表单配置重试间隔、尝试次数、订阅筛选和请求时间；未填写的项使用默认值。配置对象示例：

```json
{
  "retry_days": 3,
  "max_attempts": 3,
  "subscribed_only": false,
  "request_interval_seconds": 1,
  "timeout_seconds": 20
}
```
